# Zero Trust Cloud Access Recommendation System
### Risk-Adaptive Intelligence for Government e-Services

This repository contains the Machine Learning and Risk Engine implementation for our BCSE355L Cloud Architecture Design project. 

The system uses a hybrid approach—combining deterministic government policy rules with a Random Forest machine learning classifier—to evaluate cloud access requests and output a graded recommendation: **ALLOW**, **CHALLENGE_MFA**, or **DENY**.
